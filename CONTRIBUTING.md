# 🤝 Guía de contribución

¡Gracias por tu interés en contribuir al proyecto **Tienda TECSUP**!

Este documento establece las pautas que deben seguir las personas interesadas en reportar errores, proponer mejoras y colaborar en el desarrollo de la aplicación.

Nuestro objetivo es mantener un código ordenado, funcional y fácil de comprender.

## 1. 🐛 Reportar errores

Si encuentras un problema en la aplicación, sigue estos pasos:

1. Verifica que el error no haya sido reportado anteriormente.
2. Describe claramente el problema encontrado.
3. Indica los pasos necesarios para reproducir el error.
4. Explica cuál era el resultado esperado y qué ocurrió realmente.
5. Adjunta una captura de pantalla si es posible.

Los reportes deben ser claros y contener información suficiente para facilitar la identificación y solución del problema.

## 2. 💡 Proponer mejoras

Si deseas incorporar una nueva funcionalidad o mejorar alguna característica existente:

1. Explica qué mejora deseas incorporar.
2. Describe cómo beneficiaría a los usuarios.
3. Indica qué archivos podrían modificarse (`index.html`, `estilos.css` o `script.js`).
4. Explica brevemente cómo funcionaría la propuesta.
5. Espera la revisión de la propuesta antes de implementarla.

Toda propuesta debe estar relacionada con el funcionamiento o la presentación de Tienda TECSUP.

## 3. 🔄 Proceso de colaboración

Para colaborar en el proyecto, sigue este procedimiento:

1. Realiza una copia del repositorio mediante un fork.
2. Clona el repositorio en tu equipo.
3. Crea una rama para tus modificaciones.
4. Implementa los cambios necesarios.
5. Prueba la aplicación en el navegador.
6. Guarda los cambios mediante un commit con un mensaje descriptivo.
7. Envía un Pull Request explicando las modificaciones realizadas.

Los cambios deben ser revisados antes de incorporarse a la versión principal del proyecto.

## 4. ✅ Lista de verificación para Pull Requests

Antes de enviar un Pull Request, comprueba los siguientes puntos:

- [ ] El código está ordenado y utiliza nombres claros.
- [ ] Los archivos HTML, CSS y JavaScript funcionan correctamente.
- [ ] El cálculo del total muestra el resultado esperado de S/ 68.00.
- [ ] El diseño se visualiza correctamente en el navegador.
- [ ] No se han eliminado funcionalidades existentes sin justificación.
- [ ] Se actualizaron los archivos de documentación cuando fue necesario.
- [ ] Se probaron los cambios antes de enviarlos.
- [ ] El Pull Request incluye una descripción clara de las modificaciones.

## 5. 📌 Recomendaciones

- Mantener un código sencillo, ordenado y fácil de comprender.
- Utilizar nombres descriptivos para variables y funciones.
- Evitar modificar funciones que no estén relacionadas con la mejora.
- Respetar la estructura de archivos del proyecto.
- Comprobar el funcionamiento antes de publicar los cambios.
- Mantener actualizado el archivo `README.md` cuando se incorporen nuevas funcionalidades.

## 6. 📬 Contacto y colaboración

Si tienes dudas o deseas comunicar algún problema relacionado con Tienda TECSUP, puedes utilizar la sección **Issues** del repositorio de GitHub.

Las propuestas de mejora y contribuciones son bienvenidas, siempre que respeten las pautas establecidas en este documento.
